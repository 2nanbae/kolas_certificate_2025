# KOLAS 인증 데이터셋 설명

## 데이터 구성

### **학습 데이터 (`./data/train`)**

* 실제 학습 데이터 총량: **약 170,000건**
* 전체 데이터를 업로드할 수 없어, **각 장르(G00)별로 대표 프로그램/회차의 일부만 공개**
* 상담, 회의, 강의, 전화의 경우 프로그램 명칭과 회차 명칭은 파일명에서 임의로 추출함. 실제 명칭이나 회차가 아님.
* 공개된 샘플 구성 예시:

| 장르 | 샘플 수(싱크 기준) |
| --- | ----------- |
| 뉴스(G01) | 119건 |
| 커머스(G02) | 856건 |
| 상담(G03)  | 10건  |
| 회의(G04)  | 86건  |
| 강의(G05)  | 1건   |
| 전화(G06)  | 14건  |


---

### **검증 데이터 (`./data/valid`)**

* 검증용 데이터 **500건**을 압축하여 제공
* `./data/valid` 경로에 포함된 파일만 제출에 사용됨
* AIhub의 상담 / 회의 / 강의 / 전화 데이터를 일부 샘플링함
    - 검증에 사용한 데이터는 학습에 사용되지 아니함

## 🎛 데이터 증강(Augmentation)

### 📌 코드 설명 (`augmentor.py`)

* 모든 데이터 증강 코드는 `/augment` 디렉토리에 포함됨
* 입력 오디오 1건을 기반으로 **여러 증강 샘플을 생성하는 방식**


#### 실행 방법
```bash
## python 환경 설정
### Python 3.11.9

# venv 설정 (virtualenv or pyenv ..)
## virtualenv가 없을 경우, pip install virtualenv로 전역 설치
## python 3.11 버전이 없을 경우, 설치 후 진행
virtualenv venv --python=python3.11

## 가상환경 활성화
### (Windows) 
.\venv\Scripts\activate
### (Mac)
source venv/bin/activate

## 라이브러리 설치
pip install -r requirements.txt

### ./data/augment/input 폴더에 테스트할 mp3 / wav 파일을 업로드
### 아래 코드를 실행
python augmentor.py
```



### 📂 증강 샘플 예시

* 도메인: **커머스(Commerce)**
* 오디오 길이: **약 3초**
* 공개된 샘플 위치:

  * 입력 데이터: `./data/augment/input`
  * 출력 데이터: `./data/augment/output`

### ⏱ TPS 성능

* 입력 데이터 약 **170건**에 대해 증강 실행 테스트를 진행
* 전체 평균 처리량(TPS): **약 63.99**

* 📊 증강 항목별 평균 처리 시간 및 TPS

| 증강 항목 | 평균 처리 시간(초) | TPS(건/초) | 라이브러리 | 간단 설명 |
|-----------|----------------------|------------|------------|------------|
| **pitch** | 0.02281784768 | **≈ 43.8** | librosa | 음성의 높낮이를 조절(반음 단위 shift) |
| **phase** | 0.008434450331 | **≈ 118.6** | pydub | 파형의 위상을 반전시키는 간단한 변조 |
